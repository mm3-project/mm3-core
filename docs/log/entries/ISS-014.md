# ISS-014 — CI reference-module jobs and `test (3.13)` failed: `mm3 module check` venv installed an unpinned Playwright
- Reported: 2026-11-12 (found by Claude while getting PR #97 through CI, after the user reported "some check were not successfull")
- Type: issue (a defect in the tooling; the spec check was not repeated, see Spec check; the user can change this)
- Priority: P1 (proposed by Claude: the failure blocked the merge of PR #97 through the required checks; the user can change it)
- Area: CI, tooling (`mm3 module check`, `src/mm3/core/modcheck/build.py`)
- Spec versions at report: Core spec 0.38, Module Contract 1.0 rev 15
- Description: on PR #97 the jobs "Reference module" and `test (3.13)` failed with exit 2. `mm3 module check` builds a temporary venv with `uv pip install` and does not use `uv.lock`, so Playwright floated to 1.65 while the lock holds 1.64.1; the Chromium build installed for the locked version did not match, and the browser tests failed in that venv. The user also reported "still skipped and failed on 98" while the fix was in CI (the skipped jobs `build` and `install` depend on `test`).
- Workaround: none; the checks are required by the ruleset.
- Expected / proposed: the check venv uses the same Playwright version as the running environment, so the installed Chromium build matches.
- Requirements: CORE-281 and CORE-289, as cited in PR #98 (the module check and its venv); no spec change.
- Spec check: not repeated on 2026-11-13 (the requirement ids are taken from the PR text of #98 and were not re-searched in the spec in this turn). The cause is in the tooling, not in a spec statement, and no spec gap was identified.
- Status: fixed — PR #98 (squash-merged 2026-11-12), no spec change (Core spec 0.38 unchanged).
- Resolved in: PR #98 (merge commit 5b4e0eb9, 2026-11-12); no spec version change, no release noted. What changed: `make_venv` adds `playwright==<version of the running environment>` (helper `_browser_pin()`, no pin when the package is not installed); test `test_core_281_check_venv_pins_the_running_playwright`.
